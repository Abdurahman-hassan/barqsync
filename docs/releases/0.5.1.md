# 0.5.1 release

Date: 29 October 2026. Protocol: 11, as 0.5.0, so 0.5.1 and 0.5.0 work together.

## Scope

- [PR 40](https://github.com/Abdurahman-hassan/barqsync/pull/40): `--info=mount` is
  accepted. With `-x` and `--delete` it shows rsync's "cannot delete mount point: X",
  which 0.5.0 printed only with `-vv`, and `--info=mount0` turns it off. 0.5.0 refused
  `--info=mount` (exit 1).

Release preparation updates Cargo.toml and Cargo.lock to 0.5.1, dates the changelog, and
updates the README and status notes.

## Verification and publication

The steps are the same as for [0.5.0](0.5.0.md): merge the release preparation, verify CI
on that exact main commit, run `cargo publish --locked --dry-run` in a clean checkout of
it, then create and push the annotated `v0.5.1` tag. The release workflow builds the
macOS and Linux archives, installers and SHA-256 checksums, and creates the GitHub
release. Publishing to crates.io is a manual `cargo publish` from the same checkout.
